Local AI / Docker / Blazor

Timeline

PC 内の音声、動画、画像、ChatGPT、Codex、PC 状態などをローカルで取り込み、 時間軸にそろえて確認・再利用できるようにする統合プロダクトです。

ASP.NET Core / Blazor Docker Compose PowerShell API 連携 JSON / JSONL / ZIP Local AI Pipeline

面談での説明

「複数のローカル解析プロダクトを、Timeline という親 UI で束ねる構成を作っています。」

各サブ製品はローカル API と Docker worker を持ち、Timeline 側は直接 Docker に入らず、 公開された API と start.ps1 / stop.ps1 を呼び出します。

UI は Blazor、実行環境は Docker Compose、データ連携は JSON 契約を中心にしています。

全体アーキテクチャ

Web UI
ユーザー操作、状態確認、設定、ダウンロード。
Helper API
Windows 側で API 実行やファイル選択を仲介。
Sub API
各製品の公開契約。Timeline はここを通す。
Timeline Store
横断分析用の統合データ。

技術スタック

UI

ASP.NET Core / Blazor

.NET 10 の Blazor Server 構成。Razor Components で一覧、詳細、設定、製品管理画面を実装。

Runtime

Docker Compose

Timeline 本体は web / worker / Ollama を Compose で起動。サブ製品も Docker-first で分離。

Integration

Local API 契約

各サブ製品はローカル API、start.ps1、stop.ps1 を公開し、Timeline はそれを呼ぶ。

Data

JSON / JSONL / ZIP

サブ製品は timeline.json と convert_info.json を生成。Timeline は JSONL で統合。

AI

ローカル AI パイプライン

音声認識、話者分離、OCR、画像解析、ローカル LLM などを用途別に組み合わせる。

Safety

ローカル完結

基本は localhost とローカルファイル中心。元ファイルは読み取り専用で扱い、生成物と分離。

AI 処理の抽象化

入力 AI / 解析の種類 Timeline に渡す代表データ
音声 Speech-to-Text、話者分離、音声区間検出 話者、開始/終了時刻、文字起こしテキスト、変換情報
動画 フレーム抽出、OCR、視覚特徴、音声抽出、Speech-to-Text シーン/フレーム情報、OCR結果、音声テキスト、活動区間
画像 OCR、画像メタデータ抽出、正規化画像生成 画像記録、OCR済みテキスト、作成/撮影時刻、確認用アーティファクト
会話履歴 構造変換、Markdown整形、時刻と発話者の保持 スレッド単位の会話タイムライン、発話者、本文、作成/更新日時
PC状態 Windows host 情報収集、差分記録 OS、CPU、GPU、メモリ、ディスク、アプリ一覧、PC状態イベント

面談での言い方

AI モデル名を細かく説明するより、「音声認識」「話者分離」「OCR」「ローカル LLM」といった処理単位で説明すると、 技術選定と責務分離が伝わりやすいです。

サブ製品の役割

TimelineForAudio

音声ファイルを読み取り、話者、時刻、文字起こしテキストを持つタイムラインデータに変換。

TimelineForVideo

動画からフレーム、OCR、音声派生データ、活動区間を生成し、証跡として扱える形に変換。

TimelineForImage

画像ファイルから画像記録、OCR結果、確認用画像を生成。元画像は編集しない。

TimelineForWindowsCodex

Codex Desktop のローカル履歴をスレッド単位の JSON タイムラインに変換。

TimelineForChatGPT

ChatGPT のエクスポート ZIP を会話単位のタイムラインデータに変換。

TimelineForPC

Windows PC の状態を取得し、PC構成や環境変化をタイムラインイベントとして保存。

データフロー

元ファイルは正本として残し、サブ製品が生成したデータを Timeline 側で時間軸に寄せて扱います。

実装上のポイント

責務分離

Timeline は統合 UI と親管理に集中し、音声・動画・画像などの変換エンジンはサブ製品に分離しています。

API 契約

Web UI はサブ製品の内部実装に依存せず、公開 API と JSON 出力を使って連携します。

ローカル実行

localhost、Docker Compose、Windows PowerShell を中心に、個人PC上で完結する運用を想定しています。

確認可能性

一覧、詳細、処理状態、ダウンロード、ログを UI から確認できるようにし、変換結果を追える構成にしています。

3分で話す場合

1 Timeline は、PC 内の複数種類のデータを時間軸で扱うためのローカル統合アプリです。
2 UI は ASP.NET Core / Blazor、実行環境は Docker Compose、連携は PowerShell API と JSON 契約です。
3 音声、動画、画像、ChatGPT、Codex、PC状態をサブ製品として分離し、親の Timeline が管理します。
4 AI は音声認識、話者分離、OCR、ローカル LLM などを用途ごとに使い分けています。
5 設計上は、元ファイルを壊さず、生成データを JSON / ZIP として再利用できることを重視しています。
