製品側既定

プロモードに切り替えますか？

プロモードでは、Timeline 本体と各製品の保存先などを個別に設定できます。

個別設定に切り替えると、通常モードの自動管理から外れる項目があります。

実画面では、ここで「壊れやすくなる」「全部自分で指定する必要がある」ことを短く警告する。

Hugging Face トークンを登録

実画面では、保存時に形式確認を行い、問題があればこのモーダル内にエラーを出す。

トークンの作成
Hugging Face tokens

モデルを読むための権限を持つトークンを登録します。

自動管理へ戻しますか？

自動管理へ戻すと、保存先ルートを基準に、Timeline と各製品の保存先を自動で決めます。

プロモードで指定した製品ごとの保存先や一部の上書き設定は使われなくなります。

単なる画面切り替えとは分ける。個別設定を無効化する操作なので確認を必須にする。
